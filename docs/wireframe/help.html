使い方と対応環境

8BitDo Micro Remap · 非公式のブラウザ設定ツール

対応ブラウザとモード

Web Bluetooth 対応の Chrome / Edge。Windows、macOS、ChromeOS、Android を初期対象とします。K モード専用。実機アプリは HTTPS または localhost が必要です。

バックアップとプロファイルの違い

バックアップは保存前の復旧用データです。プロファイルは既知の割り当てを共有する JSON です。どちらもクラウド同期しません。

復元の制限

対応する設定だけを復元し、現在の未知の設定を保持します。未対応項目は確認画面でスキップとして表示します。

検証状況

これは静的な画面設計です。実装・実機の動作確認済みを意味しません。製品では単体・ブラウザフロー・実機・公式アプリ照合を個別に記録します。
