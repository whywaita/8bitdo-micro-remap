Micro.
すべての画面と状態。

62 の静的画面。接続から編集、保存、復旧まで。

接続からたどる編集画面を見る

design.md / impl.md の初期リリースを対象とした画面一覧。ダイアログ・途中経過・空状態・全エラーコードを含みます。各ページは固定サンプルです。フォームは入力可能ですが、処理や保存は行いません。

接続 → 読み込み → 編集 → 最新設定の確認 → バックアップ → 確認 → 転送 → 確定 → 照合

06 エラーと復旧

42 / connection-failed

接続できませんでした

本体の電源、K モード、Bluetooth を確認し、他のアプリとの接続を終了して再試行してください。

CONNECTION_FAILED↗43 / service-missing

対応する設定サービスがありません

選択した機器と K モードを確認して、接続し直してください。

SERVICE_NOT_FOUND↗44 / characteristic-missing

設定の通信口が見つかりません

この接続では設定を操作できません。機器とモードを確認してください。

CHARACTERISTIC_NOT_FOUND↗45 / disconnected

接続が切れました

進行中の操作を中止しました。書き込み中だった場合、本体の状態は未確認です。再接続して読み直してください。

DISCONNECTED↗46 / read-timeout

読み込みがタイムアウトしました

本体を近くに置いて再接続してください。不完全な設定は編集に使いません。

READ_TIMEOUT↗47 / incomplete-config

設定をすべて受信できませんでした

設定の一部が不足しています。全項目を受信するまで編集できません。

INCOMPLETE_CONFIG↗48 / invalid-packet

設定の応答を読み取れません

応答の形式が正しくありません。読み直しても続く場合は接続を終了してください。

INVALID_PACKET↗49 / invalid-crc

受信した設定を検証できません

データの整合性確認に失敗しました。この結果は編集に使いません。

INVALID_CRC↗50 / conflicting-page

読み込み中の設定が一致しません

同じ項目に異なる応答を受信しました。設定を最初から読み直してください。

CONFLICTING_PAGE↗51 / invalid-mapping

キーの組み合わせを保存できません

通常キーは1個、通常キーと組み合わせる修飾キーは3個までです。重複する修飾キーを取り除いてください。

INVALID_MAPPING↗52 / device-changed

本体の設定が変更されています

編集開始時と最新の設定が異なります。書き込みを停止しました。下書きを必要なら書き出し、最新設定を読み直してください。

DEVICE_CHANGED↗53 / backup-failed

バックアップを保存できません

ブラウザの保存領域が利用できないか、空き容量が不足しています。設定ページの書き込みは開始していません。

BACKUP_FAILED↗54 / write-failed

設定の転送に失敗しました

一部だけ転送された可能性があります。設定の確定は送信していません。再接続して状態を確認してください。

WRITE_FAILED↗55 / commit-failed

設定の確定を確認できません

本体に反映されたかは未確認です。バックアップを保持しています。接続し直して読み直してください。

COMMIT_FAILED↗56 / verify-failed

保存・復元の結果を確認できません

読み直しの失敗、または予定した設定との不一致を検出しました。成功として扱いません。

VERIFY_FAILED↗57 / stale-operation

この確認内容は有効ではありません

再接続、別の操作、または確定済みのため、古い確認内容では書き込めません。最新の設定から準備し直してください。

STALE_OPERATION↗58 / storage-unavailable

ローカル保存領域を利用できません

ブラウザのサイトデータ設定と空き容量を確認してください。

↗59 / recovery

設定を確認して復旧する

バックアップを消去せず、次の順番で確認してください。
